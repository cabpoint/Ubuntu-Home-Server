# Ubuntu Home Server

A personal home lab built to learn Linux system administration, networking and server management.

## Features

- Ubuntu Server 26.04
- Static IP
- SSH access
- VirtualBox
- Basic networking

## Goals

- Learn Linux administration
- Practice SSH
- Deploy Docker
- Configure Nginx
- Automate backups

## Hardware

CPU: 4 cores 
RAM: 4GB
Disk: 15GB SSD

## Network

IP: 192.168.1.151
Gateway: 192.168.1.1
DNS: 1.1.1.1
